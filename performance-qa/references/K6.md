# k6 engine mapping

Read only when the selected engine is k6.

| Common config | k6 |
|---|---|
| Concurrent users | `ramping-vus` stages |
| Request rate | `constant-arrival-rate` |
| Total iterations | `shared-iterations` |
| Ramp-up/hold/ramp-down | scenario stages or duration |
| Think time | `sleep()` |
| Response assertion | `check()` |
| p95/p99/error/throughput | `thresholds` |
| Raw result | `--summary-export` JSON |
| Native report | k6 Web Dashboard export |

The generated script resolves `${NAME}` placeholders through `__ENV.NAME`.
Existing scripts remain responsible for their request correlation and cleanup.

Smoke uses one VU and one iteration. Main execution exports summary JSON and a
self-contained Web Dashboard when the installed k6 version supports it.

For request-rate workloads, size `preAllocatedVUs` and `maxVUs` from measured
iteration duration. Insufficient VUs cause dropped iterations and invalidate
the intended arrival rate.
